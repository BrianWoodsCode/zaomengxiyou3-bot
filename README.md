# -# 游戏摊位时装自动寻找脚本

一个基于图像识别的游戏摊位自动购买脚本，用于自动推进摊位格子、刷新物品，并在第五格识别到目标时装后执行购买。

## 功能

- 自动识别当前开放的摊位格子
- 自动尝试逐级开放第二至第五格
- 解锁失败后重新识别当前状态
- 自动刷新第五格物品
- 使用图像匹配识别目标时装
- 找到目标后自动购买，并重新开始下一轮

## 运行环境

- 支持相关脚本指令的自动化工具
- 游戏窗口及分辨率与脚本坐标相匹配
- 图像识别模板：`购买.bmp`、`时装.bmp`

## 使用方法

1. 下载或克隆本仓库。
2. 在脚本工具中导入代码文件。
3. 根据实际游戏界面使用按键精灵的抓抓调整按键位置。
4. 配置购买按钮与时装的图像识别模板。
5. 建议先在测试环境中验证识别和点击逻辑，再运行完整脚本。

## 注意事项

- 本项目使用固定屏幕坐标，界面布局变化可能导致误点。
- 图像匹配阈值需要根据实际截图进行调整。
- 自动购买可能消耗游戏内货币或购买次数，请谨慎测试。
- 使用前请确认符合游戏及自动化工具的相关规则。
